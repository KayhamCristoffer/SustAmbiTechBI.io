Modelo de Dados

Schema MySQL — sustambitech

Banco relacional completo com auditoria centralizada via LogAuditoria — tabelas de lookup sem timestamps desnecessários.

Tabelas de Lookup
  • NivelUsuario Admin, Operador, Usuário
  • Status + contexto: posto/tomada/reserva
  • TipoEnergia BEV, PHEV, HEV, MHEV, FCEV, AC, DC
  • TipoConector CCS2, CHAdeMO, Type2, Tesla…
Tabelas Transacionais
  • Usuarios criadoEm · atualizadoEm
  • Enderecos lat/lng DECIMAL + logradouro
  • Postos operador, acesso, app, horário
  • Tomadas fk_posto · fk_tipoConector · kWh
  • Veiculos autonomia, bateria, preço DECIMAL(12,2)
  • Usuarios_Veiculos placa, veículo principal
  • Reservas inicio/fim previsto + real + kWh
  • Avaliacao nota 1–5 · comentário
Tabelas BI (Snapshots)
  • BI_EmplacamentosNacionais ano · estado · tecnologia · vendas
  • BI_ModelosTop maker · model · rank · total
  • BI_EstacoesNacionais UF · estações · veículos/estação
  • BI_FrotasABVE categoria · fabricante · variação
Auditoria & Views
  • LogAuditoria INSERT/UPDATE/DELETE · JSON diff
  • VIEW_PostosComStatus Power BI — postos ativos
  • VIEW_EmplacamentosBI Power BI — séries temporais
  • VIEW_TopModelosBI Power BI — ranking modelos
  • VIEW_ReservasDetalhadas Power BI — reservas + usuários
