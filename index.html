Mapa Interativo

Visualize os 57+ postos com Leaflet.js. Filtros por tipo (elétrico/híbrido), cidade e conector. Tiles OpenStreetMap/CartoDB gratuitos.

Dashboard BI

KPIs em tempo real: postos ativos, cobertura por cidade, distribuição de conectores e histórico climático com Chart.js.

Cloudflare D1 + Supabase

Banco SQLite serverless na edge com D1. Supabase PostgreSQL com triggers de auditoria, backup automático e 7 views Power BI.

Importação Excel

Upload drag-and-drop de planilhas .xlsx com SheetJS. Preview dos dados antes de importar. Log de todas as importações.

Clima Open-Meteo

Integração gratuita com Open-Meteo API. Dados atuais + previsão de 7 dias. Histórico salvo no banco para análise temporal no Power BI.

Mapa Mental BI

Diagrama visual do modelo estrela (Star Schema): tabelas fato, dimensões, views e fluxo de dados para Power BI.

Deploy & Configuração
100% gratuito com Cloudflare Pages + D1. Banco PostgreSQL via Supabase.

Cloudflare Pages (Free)

Hospedagem edge global. D1 SQLite: 5GB, 5M leituras/dia. Workers: 100k req/dia, 10ms CPU.

npm run build && wrangler pages deploy dist

Supabase (PostgreSQL)

Banco relacional com triggers, auditoria e backup. Execute full_schema.sql no SQL Editor do Supabase.

supabase link --project-ref qqlggpgsidfhqjgzbwhp

Power BI DirectQuery

Conecte o Power BI via "Obter Dados → Web" usando as URLs ?format=csv dos endpoints BI.

/api/bi/resumo-regional?format=csv
